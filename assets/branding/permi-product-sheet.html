Chrome extension manifest review

Understand extension permissions before install.

Permi helps reviewers, builders, and cautious users inspect a Chrome Web Store extension's manifest file without installing the target extension first.

What it does

Turns a Chrome Web Store URL or extension ID into a readable manifest JSON download.

  1. 1 Paste a listingUse a Chrome Web Store URL or a 32-character extension ID.
  2. 2 Fetch from GooglePermi requests the extension package from Google's Chrome update service.
  3. 3 Extract locallyThe CRX is processed in memory, then only manifest.json is saved.

Purpose

Browser extension permissions can be difficult to understand from a store listing alone. Permi gives you the underlying manifest so you can inspect requested access before installing.

Useful for

  • Checking requested permissions and host access.
  • Reviewing extension metadata before install.
  • Keeping a local manifest copy for audit notes.

Output

Permi saves a formatted manifest.json file through Chrome's downloads flow, using a unique filename based on the target extension ID.

Security and privacy posture

C Strict content security policyExtension pages default to blocking loads, then allow only local scripts, local styles, local images, and Google's CRX hosts.
L Local scripts onlyNo remote code, inline scripts, eval, or third-party runtime dependencies are used by the extension.
P Narrow permissionsThe extension requests the downloads permission plus host access for Google's CRX update and delivery endpoints.
I In-memory processingCRX bytes are streamed with size limits, parsed in the browser, and discarded after manifest extraction.
V Input validationPermi accepts only HTTPS Chrome Web Store URLs or valid 32-character Chrome extension IDs before making a request.
N No tracking or storageNo analytics, cookies, accounts, advertising identifiers, or developer-controlled remote storage are used.
